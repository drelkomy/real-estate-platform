# Project Overview

## الهدف
منصة عقارية لعرض وإدارة العقارات للبيع والإيجار، تشمل الشقق والأراضي والفيلات والعمارات، مع قابلية دعم أنواع أخرى مستقبلاً.

## المستخدمون المتوقعون
- زائر.
- باحث عن عقار.
- مالك عقار.
- وسيط/مسوق.
- مكتب أو شركة عقارية.
- مشرف محتوى.
- مدير منصة.
- دعم العملاء.

هذه أدوار أولية وليست صلاحيات نهائية. يجب اعتماد مصفوفة الأدوار قبل التنفيذ.

## المبادئ
- الأمان والخصوصية افتراضياً.
- عدم الوثوق بأي مدخل من المتصفح.
- تجربة عربية RTL أولاً وقابلة للتعدد اللغوي.
- Mobile-first وSEO-friendly.
- Modular Monolith مع حدود مجال واضحة.
- لا microservices في المرحلة الأولى.
- فصل العقار عن الإعلان.
- دعم أكثر من دولة/مدينة وعملة عند اعتماد المتطلبات.
- عدم افتراض نموذج اشتراكات أو عمولات قبل اعتماد قواعد العمل.
