# Example task request — Property Listing Search

## User request
Build the public search and filter experience for property listings.

## Required agent behavior
First perform analysis only. Do not edit files.

Inspect:
- Existing listing/property models and migrations.
- Existing location relationships.
- Existing policies and public visibility rules.
- Existing routes and Livewire components.
- Existing indexes and test coverage.

Then propose:
1. Searchable fields and exact filters.
2. Query plan and eager-loaded relationships.
3. Pagination and deterministic sorting.
4. Authorization/public visibility rules.
5. Files to change.
6. Tests including invalid filters and hidden/draft listings.
7. Index changes with evidence from query patterns.

Wait for approval before implementation.
