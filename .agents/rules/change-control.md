# Change Control

- لا تعدل إلا الملفات المدرجة في الخطة المعتمدة.
- إذا ظهر احتياج لملف إضافي، توقف واطلب توسيع النطاق.
- لا تعِد تنسيق ملفات كاملة.
- لا تحذف كوداً قديماً أو تغير سلوكاً غير متعلق بالمهمة.
- لا تغير composer.json/lock أو package.json/lock أو Dockerfile أو Compose إلا إذا كانت المهمة تتطلب ذلك وتمت الموافقة.
- لا تنفذ migrations أو أوامر بيانات إنتاجية أو deployment.
- بعد التنفيذ اعرض git diff summary واذكر أي ملف خارج النطاق.
