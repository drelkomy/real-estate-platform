# Skill: Project Analysis

استخدم هذه المهارة قبل التخطيط لمهمة أو عند استلام مشروع قائم.

1. اقرأ AGENTS.md والقواعد المنطبقة.
2. افحص git status وملفات الجذر.
3. افحص composer.json/lock وpackage.json/lock وDockerfile/Compose.
4. افحص routes وmodels وmigrations وpolicies وtests ذات الصلة.
5. ارسم وصفاً موجزاً للتدفق الحالي.
6. اذكر الحقائق المؤكدة، والافتراضات، والمعلومات الناقصة.
7. لا تعدل أي ملف في هذه المرحلة.
8. قدم ملخص تحليل ثم انتظر توجيه المستخدم.
