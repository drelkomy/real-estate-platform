# Skill: Feature Development

1. لا تبدأ قبل اعتماد خطة مكتوبة.
2. حدد acceptance criteria قابلة للاختبار.
3. اذكر الملفات المسموح تعديلها.
4. نفذ أصغر تغيير يحقق المتطلبات.
5. أضف/عدل Form Request وPolicy عند الحاجة.
6. أضف اختبارات للنجاح والفشل والصلاحيات والحالات الحدية.
7. لا تغير dependency أو schema خارج الخطة.
8. نفذ الاختبارات والفحوصات المتاحة.
9. راجع diff وتأكد من عدم وجود تغييرات جانبية.
10. قدم تقريراً صادقاً بالنتائج.
