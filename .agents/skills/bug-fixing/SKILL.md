# Skill: Bug Fixing

1. أعد إنتاج المشكلة أو حدد دليلها قبل التعديل.
2. لا تفترض السبب من رسالة الخطأ وحدها.
3. تتبع stack trace والسلوك إلى المصدر.
4. اكتب اختباراً يفشل قبل الإصلاح متى أمكن.
5. حدد أقل تغيير يعالج السبب الجذري.
6. لا تنفذ refactoring غير مطلوب.
7. شغل الاختبار الجديد والاختبارات المرتبطة.
8. وثق السبب الجذري والملفات المعدلة.
